Calliper

This object is best viewed in a browser with WebGL enabled.
Interactive 3D model unavailable.

A calliper is a precision measuring tool, used to gauge the distance between two opposite sides of an object - its outer edges, inner faces, or depth - by reading the gap against a sliding vernier scale. This calliper was modelled in PTC Creo as coursework for Mechanical CAD.
